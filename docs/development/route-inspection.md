# Private-route inspection

The archive routing switch opens a two-page comparison through the shared focus
prompt: stand at the diagram and press `E`. The first page records the old
repair diagram. The second records the actual connection. Use the arrow keys to
select a page and `Enter` to mark it reviewed. The panel lists the actual
recipients: the private headset reaches Ada and Ren, while the room speaker
reaches Ivo, the player, and Ren.

After reviewing both records, press `V` to record the verified private route.
This is one idempotent case fact. It does not grant permission to contact Ren,
make a promise, acquire evidence, or choose a resolution. `Escape` closes the
panel through the shared modal input owner and restores movement input.

The interaction is a readable comparison. It has no draggable switch, hidden
mapping, electronics simulation, or eavesdropping action.

```sh
python3 scripts/run_unity_tests.py --platform playmode --filter CommonHouse.Tests.RouteInspectionTests
```

The focused fixture checks the two records, exact recipients, modal cancel,
idempotent fact, lack of consent effects, and the generated scene's shared
focus activation. It is scripted scene evidence, not a human playtest.
