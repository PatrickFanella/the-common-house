# POC Observation Sheet

Use one copy for each new-player Case 01 session. This is a qualitative
observation aid for the proposed POC evaluation, not a recruitment script,
recording protocol, accessibility audit, or market study. Do not treat these
fields as evidence until a session has occurred.

The current proposal is five participants familiar with narrative games,
including at least one transcript-only session. That count is a proposed first
round, not a requirement to begin implementation or a basis for audience-wide
claims.

## Before the session

### Neutral control introduction

Read or adapt this introduction without explaining the case, its answer, or a
preferred route:

> This is an unfinished single-player prototype. Please explore and make the
> choices that make sense to you. Say what you are looking for or considering
> if you are comfortable doing so. You may ask for help, stop, or take a break
> at any time. I will record only the observations you have agreed to below.

Do not identify the central inference, point out clue comparisons, explain
which transmission route is preferable, or lead questions about whether the
participant liked the residents. If assistance is requested, give the smallest
help needed to continue and record both the request and the wording used.

## Case understanding and choice

Ask these after the participant has stopped or reached an outcome. Invite a
description first; use prompts only to clarify the participant's own account.
Do not supply missing facts, supporting observations, or a preferred answer.

| Topic | Neutral prompt | Blank observation |
| --- | --- | --- |
| Event reconstruction | "What do you think happened in this case?" | |
| Two-source identity inference | "What led you to that understanding?" Record the two supporting observations named, if any. | |
| Transmission recipients | "Who did you expect to hear the transmission you chose?" | |
| Decision | "What made that choice make sense to you?" | |
| Household care | "What moments with the household stood out, if any?" | |
| Transcript-only completion | "Could you find the information and make the choice you needed using the available text?" | |
| Suspense and confusion | "What, if anything, created suspense? What, if anything, was confusing rather than mysterious?" | |
| Player self-insertion | "Did the newcomer leave room for your own perspective, or did the character feel assigned to you in some way?" | |

## Proposed five-person revision triggers

Tally these only after the proposed first round. They are qualitative revision
triggers, not pass/fail evidence of market demand, final accessibility, or
audience preference. If a threshold is missed, inspect the cause and revise the
relevant design before repeating the test. Do not change a threshold to fit a
result.

| Proposed trigger | Blank tally and observation |
| --- | --- |
| At least four of five can explain the central identity inference using two supporting observations without being told the answer. | |
| At least four of five correctly identify who will hear their chosen transmission before they send it. | |
| At least three of five recall a concrete act of household care and explain why a resident's wishes affected their decision. | |
| Every participant has a reachable completion path; required hints and interventions are recorded rather than concealed. | |
| The transcript-only route preserves all essential evidence and decisions. | |

## Handling notes

Keep this completed worksheet with its build identity and date. Preserve failed
results and the assistance record alongside later improvements. This document
does not authorize recruiting participants, collecting participant data,
recording sessions, or conducting a playtest.
